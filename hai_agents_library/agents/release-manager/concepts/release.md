# Release candidate

## Definition

The role-local vocabulary for release candidate, including the supporting terms below.

## Purpose

Provide the local vocabulary used by this role and its procedures without granting authority or supplying runtime values.

## Supporting Terms

- [term:Bundle]: the reusable HAI distribution, initially released as one versioned unit.
- [term:Candidate]: the reviewed source revision and intended metadata, notes, assets, checks, and publication destination for a release.
- [term:Bundle version and release-manifest contract targets]: the local release policy.
- [term:Release authority]: the caller's established authorization for preparation, version selection, commits, tags, pushes, drafts, and public publication as applicable.
