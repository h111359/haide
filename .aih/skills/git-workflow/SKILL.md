# Optional Git workflow

Use deterministic helpers for inventory, parsing, validation, writes and evidence. Agent judgment supplies semantic interpretation and scoped patches; helper failure is an explicit capability gap, never permission to bypass validation. Read metadata first and only the relevant references; do not preload every package. Runtime execution must not modify this package or another immutable core. Disable Python bytecode. Human-owned instructions and workspace membership are read-only to the agent.

For installed AIH, the engine owns submission snapshots, global action reservation, current revisions, profile choice, state transitions and archival. Use its typed operation catalog and [semantic result shapes](references/semantic-results.md). For standalone use read [the compact contract](references/standalone.md), validate the explicit contract, and persist effective authority plus result references with the output. Do not recreate the AIH lifecycle. Declared effects are not permission grants.

Require Git and the specifically named repository; ordinary AIH work has no Git prerequisite. Installation and enablement do not authorize branch, commit, push, PR, merge, deploy, destructive operations or publication. Match each requested operation to explicit existing user authorization and configured rules. Record repository root, affected paths and root/workspace revision.

First inspect repository metadata for worktree/gitdir indirection, hooks, aliases, filters, credential helpers, signing, global config and remotes. Those mechanisms can cause effects beyond the declared roots. Use bundled `scripts/helper.py git` with the explicit standalone contract for typed status/diff/log/branch/commit/push operations. It uses argument vectors, pinned Linux confinement, disabled hooks/filters/global/system configuration and an explicitly owned runtime directory. Match declared effects to the exact operation; mutation requires scoped `.git` writes, and HTTPS push additionally requires explicit network/publication authority and the reviewed configured URL. Refer to the standalone reference for payload fields and credential references. An outside gitdir or helper with unconstrained effects is a blocker; do not widen to a common parent or copy credentials into product state. Read-only registrations never permit index/lock/reflog/worktree writes.

Produce exact scope/diff evidence before mutation. Preserve unrelated user changes; commit only authorized files and do not infer remote publication from a local commit request. Remote operations additionally require network/service authority and cannot relax filesystem containment. If the confinement backend or declared prerequisite is unavailable, report it instead of invoking arbitrary shell commands. SSH/custom transports and pull requests are explicit independently operated tool boundaries; never perform them automatically or imply that enablement authorizes them. Record operation, exit/task outcome, changed refs/files, sanitized evidence and limitations. Framework lifecycle remains the engine's responsibility; this standalone package records the scoped instruction without creating AIH state.

Read [workspace boundaries](references/workspace.md) for path/access changes, [record ownership](references/records.md) for revisions, and the relevant [execution](references/execution.md), [questionnaire](references/questionnaires.md) or [documentation](references/documentation.md) contract when performing that work.
