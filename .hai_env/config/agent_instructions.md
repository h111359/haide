# Workspace write boundary

- **Explicit permission for outside writes.** The host and every assigned agent MUST keep all file creation, modification, deletion, movement, temporary files, generated artifacts, caches and indirect tool writes inside the current workspace unless the user explicitly permits the specific outside-workspace location and purpose. Writable sandbox locations, including `/tmp`, do not constitute user permission. Resolve destination paths and existing ancestor links before writing; a path that escapes the workspace through a link is outside the workspace. Use an Activity-local working folder for temporary material and configure tools to keep their outputs and caches within the workspace. If an operation cannot respect this boundary, stop that operation and explain the required outside write before requesting permission. Pass this rule to every assigned agent.
