# Requirements clarification (draft)

Activity: `5f99ff6b-793b-475e-b184-8618582598ef`. Prepared from a read-only Business-analyst review on 2026-11-03T20:44:38Z. The criteria below are draft material for user review; they do not approve implementation mechanics.

## Accepted requirements

- HAI remains the coordinator and initializes an absent `.hai_env` environment.
- `.hai` is a shared runtime/protocol location without built-in Leader or Environment-manager agent definitions; local agent collections and configuration belong in `.hai_env`.
- Each invocation gets its own Activity-local run notebook. Invocations start with fresh context; HAI may provide explicit references to other runs. A coordinator run has a notebook, and a new Activity gets fresh notebooks. Durable cross-Activity knowledge belongs in the specification/product.
- Agents may directly update specification/product when the work fits their definition and assigned scope.
- Missing token telemetry never blocks work; record unavailable usage as unknown, not zero.
- Transcript content includes user/assistant messages, with tool activity in linked logs. Activity closure must not wait for transcript sync; preserving captured transcript and reporting gaps are desired.
- Concurrent write blocking/coordination policy remains unresolved; answer 4 did not settle it.

## Draft acceptance criteria

1. The same `.hai` runtime works with different `.hai_env` agent collections, has no built-in Leader/Environment-manager definitions, and keeps local configuration in the environment.
2. HAI initializes a missing environment while preserving any existing content.
3. Every invocation has a separate Activity-local run notebook for assignment, actions, decisions, collected information, and results, including observed token usage where available.
4. Each invocation starts with fresh context; prior run material is supplied only through explicit HAI references.
5. HAI has a coordinator notebook, each new Activity starts fresh run notebooks, and durable cross-Activity knowledge lives in specification/product.
6. An agent may edit product/specification directly when its definition and assignment permit the work.
7. Unavailable token telemetry does not block execution and is recorded as unavailable, not zero.
8. Transcripts preserve user/assistant messages, link tool logs separately, never delay Activity closure, and preserve captured data while reporting source gaps.
