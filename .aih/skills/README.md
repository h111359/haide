# Installed AIH skills

Generated from package metadata; core version 1.0.0. Ordinary discovery is read-only. Installed, enabled, available and authorized are separate states. Seven core skills default enabled; Git is optional and disabled. Enabling a skill grants no product, Git, publication or deployment authority.

| Skill | When to use | Outputs / boundaries | Default |
|---|---|---|---|
| [Analyze and plan](analyze-and-plan/SKILL.md) | Evaluate implementation choices and generate or revise the sequential plan from current submitted requirements. | Separate assessment/questions/issues records, scoped sequential plan and documentation increment. Product changes during Analysis; Inventing user approval. | Enabled |
| [Answer product questions](answer-product-questions/SKILL.md) | Answer an independent read-only question from current or explicitly requested historical product evidence. | Question-owned answer, evidence links and explicit uncertainty/freshness limitations. Changing request scope or implementation; Writing durable product documentation. | Enabled |
| [Clarify requirements](clarify-requirements/SKILL.md) | Establish what must change and why; apply reviewed submitted answers and amendments in iterative clarification. | Versioned interpretation, explained questions, exchange reviews, amendment dispositions and round results. Choosing implementation approaches; Product implementation. | Enabled |
| [Optional Git workflow](git-workflow/SKILL.md) | Inspect or perform specifically authorized Git operations in a configured repository with confined side effects. | Authorized Git result and evidence with exact repository, effects and limitations. Inferring authority from enablement; Making Git mandatory for ordinary AIH work. | Disabled |
| [Implement a plan](implement-plan/SKILL.md) | Execute an authorized current plan sequentially or plan internally for explicitly authorized direct implementation. | Scoped product changes, sequential task outcomes, incremental logs, checkpoints and verified results. Unrelated unauthorized repairs; Implicit deployment or publication. | Enabled |
| [Maintain documentation](maintain-documentation/SKILL.md) | Apply authorized documentation increments and organize current product knowledge into a balanced navigable tree. | Current knowledge, verified increments, known defects, catalogs, provenance and structural changes. Changing human business intent; Rewriting product implementation. | Enabled |
| [Reverse engineer a product](reverse-engineer-product/SKILL.md) | Build or refresh evidence-backed understanding from registered product roots without changing implementation. | Source fingerprints, observed facts, inferred knowledge, unknowns and baseline coverage evidence. Repairing implementation; Claiming static extraction demonstrates runtime behavior. | Enabled |
| [Test and verify](test-and-verify/SKILL.md) | Design scoped tests, run the maintained required suites in authorized environments, and diagnose actual failures. | Test inventory and mappings, sanitized run evidence, failures, stale and unexecuted checks. Waiving failed required tests; Unrelated product repairs. | Enabled |

Copy any package folder to a permitted ordinary workspace folder and read its [standalone contract](clarify-requirements/references/standalone.md). Each package includes its own contracts, helpers and examples; no AIH installation or fixed product-state path is required. Run `python -B <package>/scripts/helper.py integrity` before use. Metadata/resource changes are diagnosed; reconcile catalogs only through explicit maintenance with no open request or execution owner.

The official format reference is https://agentskills.io/specification. Package/helper portability tests do not establish observed compliance by a semantic agent.
