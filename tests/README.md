# Retained live adapter fixture

`fixtures/codex-smoke/` retains the isolated, failed live Codex smoke attempt: a
minimal hosting instruction, process identity records, and sanitized failure
results. It contains no copied authentication files, environment dumps or
database. The installed CLI was authenticated but failed to initialize under
the required filesystem confinement; this fixture does not establish successful
live agent execution. See `logs/codex-smoke.json` and `logs/codex-diagnostics.json`.

The executable framework test suite lives in `.aih/engine/tests/`. Reproducible
synthetic products and their complete state are generated by
`python3 -B .aih/engine/cli.py demo` under `.aih_runtime/demonstrations/`.
