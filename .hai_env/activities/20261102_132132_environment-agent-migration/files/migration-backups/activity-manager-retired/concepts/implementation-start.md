# Implementation start

## Definition

[term:Implementation start] is the first implementation attempt, marked before changes or implementation tests by `implementation_started_at`. The original marker remains immutable through retries and revisions.

## Purpose

Preserve the true first-attempt history without preventing later definition, analysis or plan revisions.
