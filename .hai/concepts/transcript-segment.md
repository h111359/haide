# Transcript segment

## Definition

A [term:Transcript segment] is a chronological source-exchange range assigned to one stable Activity ID. A chat can span Activities; an Activity can span chats and multiple segments of the same chat. Source identity alone does not uniquely identify a segment.

## Purpose

Identify a source range by session, Activity and assigned boundaries, preserving nonoverlapping attribution.
