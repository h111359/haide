## Formats

### Concept file

```
# <concept name>

## Definition

<definition explanation in free text>

## Purpose

<purpose explanation in free text>

## Supporting Terms

<purpose explanation in bulet list of supporting term elements>

## References

<reference explanation in bulet list of reference elements>

```

### Supporting term list element

```
- [<term>]: explanation in free text in single line
```

### Reference list element

```
- <relative path to another file>: explanation in free text
```

### Term format

When a string is surrounded by symnbols [ and ] - this is emphasize that this is a term, explained in concepts. Aim is this term to be explained on one place and not repeatedly clarified in multiple files.
